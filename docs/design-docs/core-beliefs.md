# Core Beliefs

1. Platform support privileges should not imply tenant observability.
2. Allowlisting is safer and easier to audit than path filtering.
3. Destructive lifecycle operations need recovery windows and durable references.
4. The UI must disclose missing contracts instead of pretending they exist.
5. Every privileged action needs an actor, reason, target, timestamp, and outcome.
6. Platform and workspace consoles should share a visual vocabulary while keeping authorization and data boundaries separate.
